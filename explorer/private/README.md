# Private assets (not committed)

Drop `BmdLettersForLearnersHattedJ-aZmR.ttf` (the learner font from the Learning Intentions
tool) in here and `make build` embeds it in the Explorer's learning intention card. The font is
licensed by its author for personal and classroom use only, so it stays out of this public
repository and off GitHub Pages; without it the card prints in Helvetica.
